# CodeAlpha Phishing Awareness Training

A short training deck that teaches people how to spot, avoid, and report phishing attacks. Made for the CodeAlpha Cyber Security Internship.

## What's inside

- `Phishing_Awareness_Training.pdf`: the 10-slide training deck

## Topics covered

1. What phishing is
2. Common types (email, SMS, voice, fake websites)
3. Red flags in an email
4. How to check a link before clicking
5. A sample phishing email with the red flags marked
6. What to do if you get a suspicious message
7. What to do if you already clicked
8. Quick quiz
9. Key takeaways

## Who it's for

Anyone who uses email, SMS, or the web, with no technical background needed.

## Disclaimer

The example email and bank name are made up and for teaching only.
